# DjangoProject

**Учебный проект по созданию веб-приложений на фреймворке Django.**

Веб-приложение на базе фреймворка **Django**, реализующее каталог товаров/услуг с контактной формой и интеграцией стилей Bootstrap. Для управления зависимостями используется пакетный менеджер **Poetry**.

---

## 🚀 Быстрый старт

### Требования
* Python 3.10 или выше
* Установленный [Poetry](https://python-poetry.org)

### Установка и настройка

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   cd DjangoProject
   ```

2. **Установите зависимости через Poetry:**
   ```bash
   poetry install
   ```

3. **Активируйте виртуальное окружение:**
   ```bash
   poetry shell
   ```

4. **Примените миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

5. **Заполните базу данных демонстрационными данными (Фикстурами):**
   ```bash
   python manage.py add_products
   ```

6. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   После этого проект будет доступен in браузере по адресу: `http://127.0.0.1:8000/`

## 🛠 Новые возможности (Фичи)

* **Кастомная команда загрузки данных (`add_products`):** Автоматизирует процесс первоначального наполнения базы данных. Она считывает данные из фикстуры `catalog_fixture.json` и корректно наполняет таблицы категорий и товаров без необходимости ручного ввода.
* **Поддержка медиафайлов:** Добавлена обработка и хранение изображений для товаров каталога в директории `media/images/`.
