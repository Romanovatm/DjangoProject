# DjangoProject

**Учебный проект по созданию веб-приложений на фреймворке Django.**

Веб-приложение на базе фреймворка **Django**, реализующее каталог товаров/услуг с контактной формой, независимый раздел блога и интеграцией стилей Bootstrap. Для управления зависимостями используется пакетный менеджер **Poetry**.

---

## 🚀 Быстрый старт

### Требования
* Python 3.10 или выше
* Установленный [Poetry](https://python-poetry.org)

### Установка и настройка

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   cd DjangoProject
   ```

2. **Установите зависимости через Poetry:**
   ```bash
   poetry install
   ```

3. **Активируйте виртуальное окружение:**
   ```bash
   poetry shell
   ```

4. **Примените миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

5. **Заполните базу данных демонстрационными данными (Фикстурами):**
   ```bash
   python manage.py add_products
   ```

6. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   После этого проект будет доступен в браузере по адресу: `http://127.0.0.1:8000/` (главная страница каталога) и `http://127.0.0.1:8000/blog/` (раздел блога).

## 🛠 Новые возможности (Фичи)

* **Кастомная команда загрузки данных (`add_products`):** Автоматизирует процесс первоначального наполнения базы данных. Она считывает данные из фикстуры `catalog_fixture.json` и корректно наполняет таблицы категорий и товаров без необходимости ручного ввода.
* **Поддержка медиафайлов:** Добавлена обработка и хранение изображений для товаров каталога в директории `media/images/` и превью статей блога в директории `media/blog/previews/`.
* **Архитектура моделей (Категории и Товары):** Реализованы связанные модели `Category` и `Product` с поддержкой хранения стоимости (`DecimalField`), изображений и автоматическим логированием времени создания и изменения записей (`DateTimeField`).
* **Модульная система шаблонов (Принцип DRY):** Интерфейс разделен на переиспользуемые блоки. Создан главный макет `base.html`, в который динамически подгружаются изолированные компоненты `header.html` и `footer.html`. Страницы каталога и блога наследуют общую структуру, заменяя только уникальный контент.
* **Детализация продуктов:** Реализована страница `product_details.html` для отображения подробной карточки конкретного товара с его описанием, ценой и изображением.
* **Независимое приложение «Блог» (CRUD на CBV):** Разработан отдельный модуль `blog` с моделью `Blog` (заголовок, содержимое, превью, дата создания, признак публикации, количество просмотров). Реализован полный цикл управления записями (создание, просмотр, редактирование, удаление) на базе Class-Based Views (`ListView`, `DetailView`, `CreateView`, `UpdateView`, `DeleteView`).
* **Бизнес-логика публикаций и просмотров:** В общем списке блога (`BlogListView`) настроена автоматическая фильтрация только опубликованных статей (`is_published=True`). При открытии детальной страницы записи (`BlogDetailView`) реализован автоматический инкремент счетчика просмотров, а после редактирования (`BlogUpdateView`) пользователь перенаправляется на страницу обновленной статьи.
* **Единая навигация между разделами:** Из приложения «Каталог» обеспечен прямой переход в раздел «Блог» (`/blog/`) через общую навигационную панель сайта (`header.html`).
